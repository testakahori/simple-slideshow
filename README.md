# Simple Slideshow

OBS（配信ソフト）にURLを貼り付けるだけで使えるスライドショー作成ツールです。
スライドショーは何個でも作成でき、それぞれに専用のURLが発行されます。

## 1. 起動方法

### 必要なもの

- **Windows 10 / 11**（Mac・Linux は非対応）
- **インターネット接続**（初回起動時のみ）

### 手順

1. このページの緑の **「Code」** ボタン → **「Download ZIP」** でダウンロード
2. ZIPファイルを右クリック →「すべて展開」で解凍する
3. 展開されたフォルダの中にある **`start.bat`** をダブルクリック

以上で完了です。Node.js などの難しいインストールは不要です。

### 初回起動について

初回のみ、以下のセットアップが自動で行われます。

```
1. Node.js のダウンロード（約 30MB・数分かかる場合あり）
2. 依存パッケージのインストール
```

黒いウィンドウにメッセージが流れ、完了するとブラウザが自動で開きます。
2回目以降はすぐに起動します。

> **注意：** セットアップ中に「このアプリがデバイスに変更を加えることを許可しますか？」
> という確認が出た場合は「はい」を押してください。

### 終了方法

黒いウィンドウ（コマンドプロンプト）を閉じるとサーバーが停止します。

## 3. スライドショーを作る

### 新規作成

1. 左サイドバーの **「+ New Slideshow」** ボタンをクリック
2. 右側の上部に **タイトル入力欄** が表示されるので、好きな名前を入力する
3. 横の **サイズ選択メニュー** で表示比率を選ぶ（後から変更可能）
4. **「保存」** ボタン（または `Ctrl + S`）を押して保存する

### タイトルの変更

ヘッダーのタイトル入力欄を直接書き換えて「保存」を押します。

### 削除

ヘッダーの **「削除」** ボタンを押すと確認ダイアログが表示されます。「削除する」を押すと完全に削除されます。

---

## 4. スライドを追加する

1. スライドショーを選択した状態で、**「スライドを追加」** ボタンをクリック
2. 新しいスライドが一覧の末尾に追加され、自動で選択される
3. 右下の編集エリアでスライドの内容を設定する
4. **「保存」** ボタンで全体を保存する

### スライドを削除する

サムネイル上にマウスを乗せると **「✕」ボタン** が表示されます。クリックすると削除されます。

## 5. スライドの種類と設定

スライドには4種類あります。上部のタブで切り替えます。

---

### 🖼 画像スライド

写真や画像ファイルを表示します。

#### 画像の追加方法（2通り）

**方法①：ドラッグ＆ドロップ**
1. エクスプローラーから画像ファイルをドラッグする
2. 青い点線の枠（ドロップゾーン）にドロップする
3. 自動でアップロードされ、プレビューが表示される

**方法②：フォルダから選択**
1. **「フォルダから選択」** ボタンをクリック
2. ファイル選択ダイアログが開くので、画像を選んで「開く」を押す
3. 自動でアップロードされる

> 対応形式：JPG / PNG / GIF / WebP など一般的な画像形式

#### その他の設定

| 設定 | 説明 |
|------|------|
| **表示方法** | **カバー**（画面全体を埋める）/ **コンテイン**（画像全体を表示）/ **フィル**（引き伸ばす） |
| **背景色** | 画像の余白部分の色。コンテイン選択時に有効 |

---

### 📝 テキストスライド

文字だけのスライドを作ります。背景色と文字色を自由に設定できます。

| 設定 | 説明 |
|------|------|
| **テキスト** | 表示したい文章を入力。改行も可能 |
| **フォントサイズ** | 文字の大きさ（px単位） |
| **テキスト配置** | 中央 / 左 / 右 |
| **フォント** | Sans-serif / Serif / Monospace / Noto Sans JP |
| **文字色** | カラーピッカーまたは16進数コードで指定 |
| **背景色** | スライドの背景色 |

---

### 💻 HTMLスライド

HTMLコードを直接入力して、自由なデザインのスライドを作ります。
CSSアニメーションや複雑なレイアウトを使いたい場合に使用します。

```html
<!-- 入力例 -->
<div style="color:white; font-size:60px; text-align:center;">
  Hello World!
</div>
```

> スタイルはインラインで記述するか、`<style>` タグを含めてください。

---

### 🎨 単色スライド

背景を1色で塗りつぶしたシンプルなスライドです。
場面転換や区切りに使うと効果的です。

| 設定 | 説明 |
|------|------|
| **背景色** | スライド全体の色 |
| **テキスト（オプション）** | 色の上に文字を重ねたい場合に入力 |
| **文字色** | テキストの色 |

---

### 共通設定（各スライドごとに設定可能）

スライド編集エリアの上部に以下の設定があります。

| 設定 | 説明 |
|------|------|
| **表示時間（秒）** | このスライドだけ表示時間を変えたい場合に設定。空欄の場合は共通設定の値を使用 |
| **トランジション** | このスライドだけ切り替え効果を変えたい場合に設定。「デフォルト」は共通設定を使用 |

## 6. スライドの順番を入れ替える

スライドのサムネイルを**マウスでドラッグ**すると順番を入れ替えられます。

### 手順

1. 移動したいスライドのサムネイルの上にマウスを乗せる
2. マウスボタンを押したまま、移動先にドラッグする
3. 挿入位置が **青いライン** で示される
   - サムネイルの左半分にドラッグ → その**前**に挿入
   - サムネイルの右半分にドラッグ → その**後**に挿入
4. マウスを離すと移動完了
5. **「保存」** ボタンで確定する

## 7. スライドショーの設定

設定バー（OBS URLバーのすぐ下）で全体的な動作を設定します。

| 設定 | 説明 |
|------|------|
| **トランジション** | スライド切り替え時のアニメーション |
| **表示時間（秒）** | 各スライドを何秒表示するか（スライド個別設定がない場合に適用） |
| **自動再生** | チェックを入れると、時間が来たら自動で次のスライドに進む |
| **ループ** | チェックを入れると、最後のスライドの後に最初に戻る |

### トランジションの種類

| 種類 | 見た目 |
|------|--------|
| **フェード** | じわっと溶けるように切り替わる（推奨） |
| **なし** | 瞬時に切り替わる |
| **スライド左** | 次のスライドが右から左に滑り込む |
| **スライド右** | 次のスライドが左から右に滑り込む |
| **ズーム** | 拡大しながら切り替わる |

## 8. OBSに表示する

### 手順

1. スライドショーを選択し、青いバーに表示されている **URL** の右の **「コピー」** ボタンをクリック
2. OBSを開き、シーンにソースを追加する
3. ソースの種類で **「ブラウザ」** を選択する
4. コピーしたURLを **「URL」欄** に貼り付ける
5. **幅・高さ** をスライドショーのサイズに合わせて設定する（OBS URLバー右側に推奨サイズが表示されます）
6. 「OK」を押すと、スライドショーが表示される

### OBSブラウザソースの推奨設定

| スライドショーのサイズ | 推奨 幅 × 高さ |
|----------------------|---------------|
| 16:9 | 1920 × 1080 |
| 9:16（縦） | 1080 × 1920 |
| 4:3 | 1024 × 768 |
| 1:1（正方形） | 1080 × 1080 |
| バナー型（4:1） | 1200 × 300 |
| カスタム | 入力したpx値をそのまま使用 |

### 編集内容をOBSに反映する

スライドショーを編集・保存すると、**約30秒以内**に自動でOBS側にも反映されます。
すぐに反映したい場合は、OBSのブラウザソースを右クリック →「プロパティ」→「更新」を押してください。

## 9. サイズ（アスペクト比）一覧

| 選択肢 | 比率 | 用途の例 |
|--------|------|---------|
| **16:9** | 横長・標準 | 一般的な配信画面、プレゼン |
| **9:16** | 縦長 | スマートフォン向け、縦型配信 |
| **4:3** | 少し横長 | クラシックなモニター、昔のTV |
| **1:1** | 正方形 | インスタグラム風、アイコン表示 |
| **バナー型（4:1）** | 横に細長い | 画面下部のテロップ、広告バナー |
| **カスタム** | 自由入力 | 特定のピクセルサイズに合わせたい場合 |

## 10. よくある質問

**Q. ダウンロードに失敗した場合は？**
A. インターネット接続を確認してから `start.bat` を再度ダブルクリックしてください。途中で止まった場合は、フォルダ内に `_node_tmp` や `_node_tmp.zip` というファイルが残っている場合があります。それらを削除してから再実行してください。

**Q. 保存し忘れたらどうなる？**
A. ページをリロードすると変更が失われます。`Ctrl + S` でこまめに保存してください。

**Q. 画像ファイルはどこに保存される？**
A. `simple slideshow/public/uploads/` フォルダ内に保存されます。

**Q. スライドショーのデータはどこに保存される？**
A. `simple slideshow/data/slideshows.json` ファイルに保存されます。

**Q. 複数のスライドショーを同時にOBSで使える？**
A. はい。スライドショーごとに異なるURLが発行されるので、複数のブラウザソースにそれぞれのURLを設定することで同時に使用できます。

**Q. 別のPCのOBSからも使える？**
A. 同じLAN内であれば使えます。OBS URLバーに表示されている `192.168.x.x` などのIPアドレス付きのURLをOBSに設定してください。

**Q. start.batを閉じるとOBSの表示も止まる？**
A. はい。サーバーが停止するとOBSでの表示も止まります。配信中はstart.batを閉じないようにしてください。
